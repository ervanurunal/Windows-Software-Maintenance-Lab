## Windows Software Maintenance Lab

### Overview

This project documents a hands-on Windows software maintenance lab completed as part of my IT Support Specialist training.

The lab focused on three common software maintenance tasks:

- Installing software that was not already installed
- Updating existing software to the newest version
- Uninstalling software that was no longer needed

These are common tasks in IT support and are important for maintaining reliable and secure Windows systems.

---

### Objectives

The objectives of this lab were to:

- Verify which applications were installed on a Windows computer
- Install Mozilla Firefox
- Update VLC Media Player
- Uninstall GIMP
- Verify software installation and removal
- Practice basic Windows software maintenance
- Develop troubleshooting and system administration skills

## Lab Walkthrough

### Step 1 — Start the Lab

I started the hands-on lab by selecting the green **Start Lab** button.

After starting the lab, an **Open Windows VM** button became available.

I selected **Open Windows VM** to access the Windows virtual machine where the software maintenance tasks were performed.

![Windows Virtual Machine](https://i.imgur.com/CdB5beS.png)

---

### Step 2 — Verify the Initial Software Setup

Before making any changes, I checked which applications were already installed on the Windows virtual machine.

I opened **Apps & Features** using the Windows search function.

The installed applications were displayed in a list.

The initial setup showed:

- Mozilla Firefox was not installed
- VLC Media Player was installed
- GIMP was installed
- VLC was running an older version

This initial verification established the starting state of the computer before performing the software maintenance tasks.

![Windows Apps and Features](https://i.imgur.com/4YcmWL1.png)

---

## Part 1 — Installing Mozilla Firefox

### Step 3 — Download Firefox

The first software maintenance task was to install **Mozilla Firefox**.

I opened Google Chrome from the Windows desktop and navigated to the official Mozilla Firefox website.

I selected the **Download Firefox** option to download the Windows installer.


![Firefox download page](https://i.imgur.com/tW9mbiG.png)

---

### Step 4 — Open the Firefox Installer

After the download finished, I selected the Firefox installer from the browser's download area.

Windows launched the installer.

If Windows displayed a security prompt asking for permission to install the software, I selected **Yes**.


![Firefox installer](https://i.imgur.com/flJijMa.png)

---

### Step 5 — Complete the Firefox Installation

The Firefox installation process began.

I followed the installation prompts and selected **Next** when required.

I waited for the installation process to finish.

After installation was completed, Firefox was available on the Windows computer.

A Firefox shortcut was also added to the desktop.

![Firefox installed](https://i.imgur.com/asiyCki.png)

## Part 2 — Updating VLC Media Player

### Step 6 — Identify the Existing VLC Version

The Windows virtual machine already had VLC Media Player installed.

The initial version was an older version of VLC.

The purpose of this task was to update VLC to a newer version.

I used **Apps & Features** to verify the existing installation.

### Step 7 — Download the VLC Installer

I opened the official VideoLAN VLC download page.

The installer was downloaded to the Windows virtual machine.

### Step 8 — Open the VLC Installer

After the download finished, I opened the VLC installer.

![VLC installer](https://i.imgur.com/FQ19PP8.png)

### Step 9 — Upgrade VLC Using Previous Settings

During the installation process, I selected:

### Step 10 — Complete the VLC Update

After the update process finished, a confirmation message indicated that VLC had been installed.

### Step 11 — Verify the Updated VLC Version

I reopened **Apps & Features** to verify that VLC had been updated.

## Troubleshooting Approach

I followed a systematic approach when working with the Windows virtual machine.

  #### 1. Identify

I first identified the software installed on the system.

  #### 2. Verify

I used **Apps & Features** to determine which applications were installed and identify the existing VLC version.

  #### 3. Install

I downloaded and installed Mozilla Firefox because it was not already present on the system.

  #### 4. Update

I downloaded the appropriate VLC installer and upgraded the existing installation.

  #### 5. Uninstall

I removed GIMP through the Windows application management interface.

  #### 6. Verify

After each task, I checked the system to confirm that the expected change had occurred.

This approach helped ensure that software changes were completed correctly and that the final system state matched the requirements of the lab.

### Cybersecurity Relevance

Software maintenance is an important part of cybersecurity and IT operations.

Keeping applications updated can help organizations address software vulnerabilities and maintain supported versions of applications.

Uninstalling unnecessary software can also reduce the number of applications present on a system and help with software management.

**This lab provided practical experience with::**

- Software installation
- Software updates
- Software removal
- Application version verification
- Windows endpoint management
- Basic system maintenance

These skills are relevant to cybersecurity because SOC Analysts and IT security teams often work with Windows endpoints and need to understand the software running on those systems.

During security investigations, knowing how applications are installed, updated, and removed can help analysts understand the software environment of an affected endpoint.
